### Option 2: Share on Local Network

**For testing on multiple devices:**

1. Start a local server:
   ```bash
   python3 -m http.server 8000
   ```

2. Find your computer's IP address:
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig`

3. On other devices (same WiFi), visit:
   ```
   http://YOUR-IP:8000
   ```

## ❓ Troubleshooting

### Channel Won't Play?

**Try these:**
1. ✅ Check internet connection
2. ✅ Enable Low Bandwidth Mode
3. ✅ Try a different channel
4. ✅ Refresh the page
5. ✅ Try a different browser

### Buffering Too Much?

**Solutions:**
1. ✅ Enable Low Bandwidth Mode
2. ✅ Close other apps using internet
3. ✅ Move closer to WiFi router
4. ✅ Try during off-peak hours

### No Sound?

**Check:**
1. ✅ Device volume is up
2. ✅ Browser isn't muted
3. ✅ Click on video to unmute (browsers block autoplay with sound)

### Site Not Loading?

**Solutions:**
1. ✅ Clear browser cache (Ctrl+F5 or Cmd+Shift+R)
2. ✅ Disable browser extensions
3. ✅ Try incognito/private mode
4. ✅ Use a different browser
